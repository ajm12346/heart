# HeartLens 모델 카드

## 개요

- 모델 버전: `uci-logistic-2026.08.13-v1`
- 목적: UCI Heart Disease 자료에서 질환 존재 가능성의 상대적 3단계 분류
- 알고리즘: L2 정규화 로지스틱 회귀
- 학습자료: Cleveland, Hungary, Switzerland, VA Long Beach processed 자료 920건
- 목표값: UCI `num=0` 대 `num=1~4`

## 성능

환자 단위로 기관·목표값을 층화한 5겹 교차검증의 out-of-fold 예측 기준입니다.

| 지표 | 결과 |
|---|---:|
| AUROC | 0.8843 |
| Average precision | 0.8977 |
| Brier score | 0.1471 |
| 고위험 경계 | 0.510 |
| 고위험 경계 민감도 | 0.8527 |
| 고위험 경계 특이도 | 0.7737 |
| 낮음/주의 경계 | 0.313 |

기관별 외부검증 AUROC는 Cleveland 0.865, Hungary 0.853, Switzerland 0.702, VA Long Beach 0.714였습니다. 기관이 바뀌면 성능이 낮아질 수 있다는 중요한 제한을 보여줍니다.

전체 수치, 혼동행렬, 교정구간, 교차검증 각 fold와 기관별 검증 결과는 `evaluation.json`에 있습니다.

## 전처리

- 수치형: 학습자료 중앙값 보완 후 평균·표준편차 표준화
- 범주형: 학습자료 최빈값 보완 후 고정 범주 one-hot 표현
- 모든 원변수: 결측 표시변수 추가
- 환자 단위 분할 후 각 학습 fold 안에서만 전처리값 산출

## 출력

- 낮음: 확률 < 0.313
- 주의: 0.313 ≤ 확률 < 0.510
- 높음: 확률 ≥ 0.510

이 확률은 UCI 표본에서의 모델 출력이며 보편적인 임상 확률이나 미래 절대위험이 아닙니다. 개인별 설명은 표준화 입력과 로지스틱 회귀계수의 곱을 원변수별로 합산한 값입니다. 설명은 연관성이지 인과관계가 아닙니다.

## 금지된 사용

- 심장병 확진 또는 배제
- 급성 흉통 등 응급상황 판단
- 치료·약물·검사 지시
- 개인의 5년·10년 심혈관 사건 절대위험 추정
- 의료진 검토 없는 자동 선별 또는 불이익 결정

## 알려진 제한

- 1980년대 해외 환자자료로 국내 대표성이 없음
- 기관별 유병률과 결측패턴 차이가 큼
- Switzerland와 VA 자료의 양성 비율이 높아 선택편향 가능성이 큼
- 일부 검사는 일반 사용자가 알기 어렵고 의료진 확인이 필요함
- 전향적 검증, 국내 외부검증, 임상 유효성 검증 및 인허가 검토가 수행되지 않음

## 변경관리

모델, 전처리값, 임계값 또는 변수정의를 바꾸면 버전을 올리고 5겹 교차검증·기관별 외부검증·입력검증 테스트를 모두 다시 수행해야 합니다.
