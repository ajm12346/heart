# HeartLens

HeartLens는 사업계획서의 핵심 범위를 구현한 **로컬 웹 기반 심장병 위험도 분류 연구용 시제품**입니다. 설치형 프레임워크 없이 Python 표준 라이브러리만으로 웹 화면을 실행하며, 입력값은 저장하지 않습니다.

## 빠른 실행

Windows에서 `start.cmd`를 더블클릭합니다. 브라우저가 자동으로 열리지 않으면 아래 주소로 접속합니다.

```text
http://127.0.0.1:8765
```

종료할 때는 실행 창에서 `Ctrl+C`를 누릅니다.

직접 실행하려면 Python 3.10 이상에서 다음 명령을 사용합니다.

```powershell
python app.py
```

웹 프로그램의 추론 기능은 외부 패키지가 필요하지 않습니다. 모델을 다시 학습할 때만 `numpy`와 `pandas`가 필요합니다.

## 구현 기능

- 13개 검사·문진 항목의 범위·단위·필수값 검사
- 선택검사 결측 보완과 입력품질 경고
- 낮음·주의·높음 3단계 상대적 분류
- 로지스틱 회귀 항목별 기여도 설명
- 급성 흉통·호흡곤란 등 응급증상 우선 경고
- 인쇄/PDF 및 CSV 결과 내보내기
- 모델 버전, 검증성능, 데이터·적용 한계 표시
- 입력정보 무저장 및 보안 응답 헤더

## 모델과 검증

- UCI Heart Disease 네 기관 processed 자료 920건 전체 사용
- 환자 단위·기관/목표값 층화 5겹 교차검증
- 한 기관씩 제외한 외부검증 결과 기록
- L2 정규화 로지스틱 회귀
- 수치형 중앙값, 범주형 최빈값 보완 및 결측 표시변수
- 교차검증 예측에서 고위험 경계의 목표 민감도 0.85 이상을 탐색

정확한 수치는 `model/evaluation.json`과 화면 하단에서 확인할 수 있습니다. 기관별 외부검증에서 성능이 낮아지는 경우가 있으므로 임상적 일반화를 주장하지 않습니다.

## 파일 구조

```text
app.py                  로컬 웹 서버와 API
risk_engine.py          입력검증·추론·설명 엔진
static/                 화면 HTML/CSS/JavaScript
modeling/train_model.py 재현 가능한 모델 학습
model/                  모델 JSON과 평가 결과
data/raw/               UCI 원자료
data/processed/         네 기관 결합 데이터
tests/                  자동 테스트
```

## 안전상 사용 제한

이 프로그램은 공개 UCI 자료에서 학습한 연구·교육용 상대적 분류기입니다.

- 심장병을 확진하거나 배제하지 않습니다.
- 개인의 5년·10년 미래 절대위험을 계산하지 않습니다.
- 응급상황을 판정하거나 치료를 권고하지 않습니다.
- 국내 환자를 대상으로 외부검증하지 않았습니다.

현재 지속되는 흉통, 갑작스럽거나 심한 호흡곤란, 식은땀·실신, 팔·턱·등으로 퍼지는 통증이 있으면 프로그램 결과를 기다리지 말고 119 또는 응급의료기관에 연락해야 합니다.
